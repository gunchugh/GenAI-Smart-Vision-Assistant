# 🤖 GenAI Smart Vision Assistant

An AI-powered Computer Vision Assistant built using **YOLOv11, ByteTrack, BLIP, Whisper, ViLT, Flask, HTML, CSS, and JavaScript**.

This project can detect, track, caption, analyze, and answer questions about images using multiple state-of-the-art AI models through an interactive web interface.

---

## 🚀 Features

- 🖼️ Image Object Detection (YOLOv11)
- 🎥 Video Object Detection
- 🎯 Multi Object Tracking (ByteTrack)
- 🤖 AI Image Captioning (BLIP)
- 🎤 Speech-to-Text (Whisper)
- ❓ Visual Question Answering (ViLT)
- 📊 Detection Analytics Dashboard
- 📄 AI PDF Report Generation
- 🔊 Text-to-Speech Caption
- 🌐 Modern Responsive Web Interface

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/gunchugh/GenAI-Smart-Vision-Assistant.git
```

Move into project folder

```bash
cd GenAI-Smart-Vision-Assistant
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
